# relay feedback

Native macOS workspace for your terminal, editor, browser and coding agents. One workspace per project.

This is the public place for bug reports and feature requests for relay.

## Get relay and find help

- [Website and download](https://relay-app.dev/en/)
- [Documentation](https://relay-app.dev/en/docs/)
- [MCP bridge documentation](https://relay-app.dev/en/docs/#mcp-bridge)
- [Instagram](https://www.instagram.com/relay.app.dev/)
- Email: [support@relay-app.dev](mailto:support@relay-app.dev)

## Report a bug

[Search existing issues](https://github.com/relayappdev/feedback/issues) first, then [open an issue](https://github.com/relayappdev/feedback/issues/new).

Please include:

- Your relay version and macOS version.
- Steps to reproduce the problem.
- What you expected and what happened instead.
- Relevant screenshots or short log excerpts, with personal information and secrets removed.

## Request a feature

[Open an issue](https://github.com/relayappdev/feedback/issues/new) and describe the task you want to accomplish, what gets in the way, and any workaround you use today.

Reports in English or German are welcome.

## Private support

For account, billing, license or security questions, email [support@relay-app.dev](mailto:support@relay-app.dev). Do not post license keys, passwords, tokens or personal account details in public issues.
